Cloud Controls Matrix (CCM) reference data: CSA's notices
=========================================================

The CCM reference files in this folder are CSA's Cloud Controls Matrix text.
CSA publishes each version of the matrix with its own copyright notice, and its terms say
that "the trademark, copyright or other notices may not be removed". Each version's notice
is reproduced below word for word, copied by program from the notice cell of CSA's published
workbook for that version (the cell's trailing space is not carried). These files are
Cloud Security Alliance works, © Cloud Security Alliance, all rights reserved; the plugin's
Apache License 2.0 does not cover them (see the plugin's NOTICE).

Which notice covers which file
------------------------------

CCM-4.0.13-merged.csv: Used for CAIQ v4.0.1, v4.0.2 and v4.0.3 questionnaires. Covered by CSA's CCM 4.0.13 notice.
  Notice: CCM 4.0.13, from CSA's workbook CCMv4.0.13_Generated-at_2024-10-31.xlsx (SHA-256 15ed2749457430197e18d134f2c4d09e1fd432ec4942cbea2105f5ff9ac0ae80).

CCM-4.1.0-merged.csv: Used for CAIQ v4.1.0 stamped CCM 4.1.0, and for CAIQ-Lite v4.1.0. Covered by CSA's CCM 4.1.0 notice.
  Notice: CCM 4.1.0, from CSA's workbook CCMv4.1.0-generated_at_2026_01_13.xlsx (SHA-256 5e721628c8ab297bdbd355afa4c01699971fcbb9cb16802ccb9d42c7176ab32b).

CCM-4.1.1-merged.csv: Added by this plugin: CSA's CCM 4.1.1, for a CAIQ v4.1.0 stamped CCM 4.1.1, generated from CSA's CCM 4.1.1 workbook (see VERSION.txt). Covered by CSA's CCM 4.1.1 notice.
  Notice: CCM 4.1.1, from CSA's workbook CCMv4.1.1-generated_at_2026_10_02.xlsx (SHA-256 6ebb2207f805ef952fa8450e6863cd98bc708af76bedd24a536925cdec460205).
