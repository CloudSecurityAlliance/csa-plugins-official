Reference data in this folder: versions, sources and checksums
================================================================

Plugin valid-ai-ted-scorer 1.0.1. Eight reference files: the four from CSA's published
Valid-AI-ted Scorer package, unchanged, and four the plugin adds, so that every CAIQ and
AI-CAIQ release CSA publishes has the reference data it pairs with. SKILL.md's A-02 table says
which file each questionnaire uses. Their notices are in NOTICE-CCM.txt and NOTICE-AICM.txt,
beside them.
